# Algorithms and Software

This directory contains lightweight utilities for the principal SOST graph dynamic.

- `sost_core_v1_1_0.py` — edge indexing, legal triangle moves, invariant labels;
- `SOST_Orbit_Label_v1_1_0.py` — compute the invariant label of a JSON graph;
- `SOST_Equivalence_Decision_v1_1_0.py` — theorem-based equivalence decision for `n>=6`;
- `SOST_Six_Vertex_Representatives_v1_1_0.json` — one exact representative for each of the `96` six-vertex invariant labels.

The utilities require only the Python standard library.
